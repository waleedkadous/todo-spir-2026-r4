The hydration strategy is textbook:
1. `useState<Todo[]>([])` — server and client both start with empty array → **no mismatch**
2. `useEffect(() => { setTodos(loadTodos()); setIsLoaded(true); }, [])` — loads from localStorage **after** mount
3. `isLoaded` guard prevents the save-effect from writing `[]` back to localStorage on first render (the race condition this prevents is exactly right)
4. `storage.ts` functions all guard `typeof window === "undefined"` — safe if accidentally called during SSR
